- Python：后端服务（FastAPI）、数据与模型处理、课程实验台（playground）

- Rust：部分性能敏感课程与系统编程实践

### 现代前端工程化最佳实践

**新增** 本节详细介绍项目中采用的现代前端开发模式

#### Vue 3 Composition API 深度使用
- **`<script setup>` 语法**：所有组件使用编译时转换的语法糖，提供更好的性能和类型推导
- **响应式状态管理**：使用 `ref()` 和 `reactive()` 管理组件状态
- **生命周期钩子**：`onMounted()`、`onUnmounted()` 等组合式函数
- **计算属性与监听器**：`computed()`、`watch()` 实现复杂的数据派生

#### TypeScript 类型系统
- **严格类型检查**：启用 `strict: true`，确保类型安全
- **接口定义**：完整的前后端数据类型定义
- **泛型支持**：API 请求函数的类型安全封装
- **路径映射**：`@/*` 别名简化导入路径

#### Vite 构建系统优化
- **ESM 原生支持**：利用浏览器原生 ES 模块
- **热模块替换 (HMR)**：开发时即时更新，无需刷新页面
- **按需编译**：只编译修改的文件，提升开发体验
- **生产优化**：自动代码分割、Tree Shaking、压缩

#### CSS 架构设计
- **CSS 变量系统**：统一的色彩、间距、字体变量
- **模块化样式**：每个组件独立的样式文件
- **响应式设计**：Flexbox 布局，适配不同屏幕尺寸
- **主题支持**：深色主题，符合开发者偏好

## 故障排查指南
- 后端 API 无法访问
  - 检查 FastAPI 是否在 0.0.0.0:8000 启动
  - 确认 CORS 配置允许前端域名
- 前端代理无效
  - 确认 vite.config.ts 中 /api 代理指向 http://localhost:8000
  - 确认前端已构建并挂载静态资源
- **前端开发问题**
  - **TypeScript 类型错误**：检查 tsconfig.json 配置，确保类型定义完整
  - **Vue 组件不更新**：确认使用正确的响应式 API（ref/reactive）
  - **样式不生效**：检查 CSS 变量定义和 scoped 样式作用域
- MCP 工具调用失败
  - 检查 Python MCP 服务器是否正常启动
  - 确认 stdio 客户端参数与工具名一致
- 数值计算不一致
  - 对照 Julia 与 PyTorch 的自动微分与梯度计算
  - 核对数值精度与数值稳定性（如 logsumexp 的稳定实现）
