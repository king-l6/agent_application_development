模块以 42 个编号子目录构成线性教学序列，每个子课题遵循统一单元结构：`docs/en.md`+`docs/zh.md`（理论）、`code/main.py`（Python/TS 原型）、`assets/*.svg`（架构图）、`outputs/skill-*.md`（技能产物）、`quiz.json`（能力校验），形成“读-看-跑-测”闭环。

内部按主题分层递进：
- 控制流层（01–05）：ReAct 单轮循环、ReWOO 计划-执行解耦、Reflexion 反思缓冲、Tree-of-Thoughts/LATS 搜索策略、Self-Refine/Critic 自我修正；均以 stdlib 实现 ToyLLM + ToolRegistry 的最小骨架，强调 Turn Budget 与观察格式化边界。
- 运行时框架层（06–18）：工具注册表、MemGPT/Mem0 虚拟/混合记忆、Voyager 技能库、HTN/进化规划、Anthropic Workflow、LangGraph 有状态图（StateGraph/Runner/Checkpointer）、AutoGen Actor 模型、CrewAI 角色 Crew、OpenAI/Claude Agents SDK、Agno/Mastra 运行时选型。
- 可靠性与运维层（19–27）：SWE-bench/GAIA/WebArena/OSSWorld 基准套件、Computer Use 安全约束、Pipecat/LiveKit 语音管线、OTel GenAI 规范、观测平台接入、辩论拓扑、失败模式检测、Prompt Injection 防御。
- 工程化收敛层（28–42）：编排模式选择 → 生产运行时形状 → Eval 驱动开发 → 真实仓库 Workbench → 最小 Workbench → 指令即约束 → 仓库记忆/状态 Schema → 初始化脚本 → Scope Contract → 运行期反馈环 → 验证门 → Reviewer Agent → 多会话交接 → 综合 Capstone。

最终产出 `agent-workbench-pack`（42 章 outputs 下）通过 JSON Schema（`agent_state.schema.json`、`scope_contract.schema.json`、`task_board.schema.json`）定义跨 agent 的状态契约，并由 `scripts/init_agent.py`、`verify_agent.py`、`generate_handoff.py`、`run_with_feedback.py` 等 CLI 脚本驱动，形成可分发的标准化工件。
