- 实验模块以单文件放在 `src/data/modules/<name>.js`，默认导出一个对象，包含 `phase`/`lesson`/`order`/`inputs[]`/`run(inputs)` 字段，由 `playground.js` 通过 `import.meta.glob` 自动收集并按 phase 分组。
- 所有需要跨页面共享的课程元数据（PHASES/GLOSSARY/ARTIFACTS）均由 Node 脚本从 Markdown 源解析生成，产出文件以 `.generated.js` 命名并由 `predev`/`prebuild` 钩子自动重建，禁止手动编辑。
- 静态页面的文案与计数（lessons/phases/outputs）不硬编码，而是由 `site/build.js` 扫描源码后正则替换到 `index.html`、`catalog.html`、`lesson.html`、`prereqs.html`、`cmdpalette.js` 中，保持单一事实来源。
- 主题与进度状态通过 `localStorage` 持久化，并在 `DOMContentLoaded` 时初始化，语言切换通过自定义 `langchange` 事件驱动 `renderPhases()` 与 `populateStats()` 重新渲染。
