本模块包含两套并列的前端与一套构建管线：
- **传统静态站点**（`site/*.html` + `app.js` / `header.js` / `progress.js` / `cmdpalette.js`）：根级 `build.js` 解析仓库根目录的 `README.md`、`ROADMAP.md`、`glossary/terms.md` 以及 `phases/*/outputs/` 下的 frontmatter 产物，生成 `data.js`（PHASES/GLOSSARY/ARTIFACTS），再由 `app.js` 渲染阶段卡片、模态框、进度条与滚动动画；同时同步更新 `sitemap.xml`、`llms.txt` 与 README 中的统计数字。
- **Vue 3 SPA 实验台**（`site/vue-app/summary/`）：Vite 6 构建输出到 `site/summary/`；`src/main.js` 挂载 `App.vue`，顶层 Tab 在“学习笔记”（`DayContent`）和“实验台”（`PlaygroundView`）间切换；`src/data/playground.js` 通过 `import.meta.glob('./modules/*.js', { eager: true })` 自动发现并分组 `modules/` 下的实验模块，每个模块导出 `{ name, phase, lesson, order, inputs[], run(inputs) }`，返回统一 block 类型（keyvalue/table/list/text/score/json）供 `PlaygroundView` 渲染。
- **数据生成管线**：`package.json` 的 `predev`/`prebuild` 钩子依次执行 `scripts/gen-code-refs.mjs`、`gen-checkpoint-snapshot.mjs`、`gen-wiki.mjs` 生成 `checkpointSnapshot.generated.js`、`codeRefs.generated.js`、`wiki.generated.js` 等只读数据文件，再交由 Vite 打包。
