- **内容即代码（Content-as-Code）架构**：`README.md` 与 `ROADMAP.md` 作为 Single Source of Truth，由 `site/build.js` 解析并生成前端数据源 `data.js`，使文档与站点强一致。
- **统一构建与制品分发管线**：构建脚本扫描 `phases/**/outputs/` 下带 YAML Frontmatter 的 Prompt/Skill/Agent/MCP 文件，经 `scripts/install_skills.py` 或 `skills.sh` 一键注入 Claude、Cursor、Codex、OpenClaw、Hermes 等代理环境。
- **多端适配与静态化部署**：基于 Vercel 托管，`vercel.json` 配置路由重写与缓存；构建同步产出 `sitemap.xml` 与 `llms.txt`，优化搜索引擎与 LLM 索引。
- **跨模块元数据同步**：构建阶段自动更新 `README.md` 中的流量统计徽章与课程总数，确保营销入口与实际规模实时对齐。
- **子模块职责边界**：`curriculum_phases` 定义 20 阶段先修依赖图；`glossary_docs` 提供术语与误区澄清；`guardrails_sandbox` 编排安全护栏与教学实验；`memory_state` 持久化进度与面试话术规范；`scripts_tooling` 提供脚手架、审计、编目与部署工具；`site_static` 聚合 README/ROADMAP/glossary 生成 Vue 3 交互式站点。
