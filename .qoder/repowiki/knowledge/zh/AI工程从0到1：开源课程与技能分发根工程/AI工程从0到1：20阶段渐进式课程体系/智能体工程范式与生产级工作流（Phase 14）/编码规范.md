- 每个子课题目录严格遵循 `docs/{en,zh}.md` + `code/main.py` + `assets/*.svg` + `outputs/skill-*.md` + `quiz.json` 的固定布局，便于自动化抽取与双语发布。
- 所有智能体循环实现均显式声明 `max_turns` / Turn Budget 并在达到上限时追加 `final` 类型 Turn，防止 LLM 陷入无限思考-行动循环。
- ToolRegistry 统一采用 `register(name, fn)` 注册、`dispatch(name, args)` 调用并捕获异常返回 `error:` 前缀字符串，使错误观察能回流给 LLM 进行自我修正。
- 涉及状态管理的章节（LangGraph、Workbench）使用 JSON Schema 文件（`schemas/*.schema.json`）作为唯一真相源，代码侧仅做浅拷贝合并更新，保证状态变更原子性与可序列化。
- ToyLLM 以“脚本化策略”（list of dicts 或模板）替代真实 LLM 调用，确保示例离线可复现且 token 用量可精确统计，便于对比不同控制流的成本。
- 多智能体/多节点场景优先采用消息传递或共享 State 图的解耦设计，并通过 `PausedAtNode` 等显式暂停异常表达人机协作断点，而非隐式阻塞。
